# Python Reference Library

Este repositório funciona como um **guia de consulta rápida e base de conhecimento** para meus estudos e projetos em Python. Ele foi estruturado para ser uma biblioteca viva, abrangendo desde os conceitos fundamentais da linguagem até tópicos avançados como Programação Orientada a Objetos, Integração com Bancos de Dados e Machine Learning.

---

## 🗂️ Estrutura do Repositório

O conteúdo está organizado de forma progressiva e modular para facilitar a busca por referências de código:

- **[Python I - Básico](./Python%20I%20-%20Basico/)**
  - Sintaxe fundamental, tipos de dados, variáveis, operadores, estruturas condicionais e loops.
- **[Python II - Intermediário](./Python%20II%20-%20Intermediario/)**
  - Funções, escopo, estruturas de dados (listas, dicionários, tuplas, sets) e manipulação básica.
- **[Python III - POO](./Python%20III%20-%20POO/)**
  - Programação Orientada a Objetos: classes, atributos, métodos, herança, polimorfismo e encapsulamento.
- **[Python IV - Avançado](./Python%20IV%20-%20Avançado/)**
  - Tópicos complexos: *Generators*, *Iterators*, *Decorators*, exceções customizadas e *Context Managers*.
- **[Python V - Outros](./Python%20V%20-%20Outros/)**
  - Manipulação de arquivos (I/O), expressões regulares (RegEx) e módulos utilitários da linguagem.
- **[Aplicações, Exemplos e Exercícios](./Aplicacoes_Exemplos_Exercicios/)**
  - Scripts práticos, resolução de problemas e consumo de APIs externas (ex: requisições com a PokeAPI).
- **[Banco de Dados](./Banco%20de%20Dados/)**
  - Conexão e manipulação de bancos relacionais e não-relacionais (ex: SQL Server com `pymssql`).
- **[Machine Learning](./Machine%20Learning/)**
  - Introdução teórica e conceitos básicos de ML aplicados com Python.
