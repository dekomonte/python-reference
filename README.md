# Referencias_Python

# 🐍 Python Reference Library

Este repositório funciona como um **guia de consulta rápida e base de conhecimento** para meus estudos e projetos em Python. Ele foi estruturado para ser uma biblioteca viva, abrangendo desde os conceitos fundamentais da linguagem até tópicos avançados como Programação Orientada a Objetos, Integração com Bancos de Dados e Machine Learning.

---

## 🗂️ Estrutura do Repositório

O conteúdo está organizado de forma progressiva e modular para facilitar a busca por referências:

* **[Python I - Basico](./Python%20I%20-%20Basico/)**
  * Sintaxe fundamental, tipos de dados, variáveis, operadores, estruturas condicionais e loops.
* **[Python II - Intermediario](./Python%20II%20-%20Intermediario/)**
  * Funções, escopo, estruturas de dados (listas, dicionários, tuplas, sets) e manipulação básica de dados.
* **[Python III - POO](./Python%20III%20-%20POO/)**
  * Programação Orientada a Objetos: Classes, atributos, métodos, herança (incluindo múltipla herança), polimorfismo e encapsulamento.
* **[Python IV - Avançado](./Python%20IV%20-%20Avançado/)**
  * Tópicos complexos como *Generators*, *Iterators*, *Decorators*, tratamento de exceções customizadas e *Context Managers*.
* **[Python V - Outros](./Python%20V%20-%20Outros/)**
  * Manipulação de arquivos (leitura/escrita), expressões regulares, módulos úteis e utilitários da linguagem.
* **[Aplicacoes_Exemplos_Exercicios](./Aplicacoes_Exemplos_Exercicios/)**
  * Scripts práticos, resolução de exercícios e consumo de APIs externas (ex: requisições usando a PokeAPI).
* **[Banco de Dados](./Banco%20de%20Dados/)**
  * Exemplos de conexão e manipulação de bancos de dados relacionais e não-relacionais (ex: SQL Server com `pymssql`).
* **[Machine Learning](./Machine%20Learning/)**
  * Introdução e conceitos básicos de ML aplicados utilizando Python.
